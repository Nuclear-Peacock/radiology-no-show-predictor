# Medical No-Show Predictor (Educational Demo)

### ⚠️ Disclaimer
**This project is for educational purposes only.** The model provided here is a demonstration of machine learning logic using public health data. It should **not** be used to make clinical or administrative decisions in a real-world healthcare setting.

### About
This tool demonstrates how AI can identify patterns in appointment data (like lead time and age) to predict the likelihood of a patient missing their appointment.

### Data Source
This model is trained on the publicly available "Medical Appointment No Shows" dataset (Kaggle).
